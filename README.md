# hasanozkan.github.io

Field notes on AI systems and software architecture, built by GitHub Pages
(Jekyll). Live at <https://hasanozkan.github.io>.

**Adding a note:** one Markdown file in `_posts/` named
`YYYY-MM-DD-slug.md`, with `title`, `lede`, `description`, `tags` and an
optional 1200×630 `image` in its front matter. Push to `main`; Pages builds it.

Social cards are rendered from `og/*.html` with headless Chrome.
